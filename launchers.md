# Application Launchers

This project provides the following executable shortcuts:

- `dist/EMG Acquisition/EMG Acquisition.exe` — main scope (supports 1ch and 5ch via arguments)
- `dist/EMG Launcher/EMG Launcher.exe` — launcher window with buttons
- `Start_EMG_1ch.bat` — batch launcher for 1 channel simulation
- `Start_EMG_5ch.bat` — batch launcher for 5 channel simulation
